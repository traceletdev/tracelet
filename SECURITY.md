# Security Policy

## Supported Versions

The latest released version of tracelet receives security fixes. Please upgrade
to the newest release before reporting an issue.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via GitHub's
[private vulnerability reporting](https://github.com/traceletdev/tracelet/security/advisories/new)
or by email to **moizwasti@gmail.com**. Include:

- a description of the issue and its impact,
- steps to reproduce (a minimal proof of concept if possible),
- affected version(s).

You can expect an acknowledgement within a few business days. We'll keep you
updated as we investigate and coordinate a fix and disclosure.
